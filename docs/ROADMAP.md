# 路线图

当前版本：v0.1.0-alpha.1。项目已从节点切换扩展为本地网站分流配置工具，首版采用直接应用方案。

## 已完成的开发预览

- [x] Electron 桌面界面，项目内 nvm / Node.js 环境、精确依赖与 lockfile。
- [x] Clash Verge Rev 发现、当前订阅识别、节点与策略组读取。
- [x] 独立 Mihomo 运行文件适配。
- [x] 网站与出口映射、域名规范化、匹配顺序和重复检查。
- [x] 预览、内核校验、持久脚本写入、运行配置重载和规则回读。
- [x] 备份、撤销、外部修改检测、幂等、操作互斥和中断恢复。
- [x] 使用合成配置的自动检查、Electron 界面自检与真实 Mihomo 代理链集成验证。
- [x] macOS Apple Silicon 开发打包与 SHA-256 文件。

## 正式分发前

- [ ] 用户验收界面、文案和桌面操作体验。
- [ ] 使用目标版本的真实 Clash Verge Rev 完成订阅更新、切换配置及重启后的完整兼容验收。目前订阅重新生成在合成配置上回放验证。
- [ ] 扩大客户端 / 内核版本兼容矩阵，处理不标准的扩展脚本与没有专属脚本的配置。
- [ ] 核验 Windows / Linux 原生客户端、文件权限、命名管道及打包行为。
- [ ] macOS Developer ID 签名、公证及正式安装分发方案。
- [ ] 面向普通用户的升级与迁移说明。

## 后续效率功能

- [ ] 网站规则搜索、批量导入与导出。
- [ ] 可选的关联域名清单及来源、更新时间说明。
- [ ] 多订阅规则迁移、失效出口修复引导。
