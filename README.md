# Node Switcher · 快速切换节点

面向普通用户的开源代理节点快捷切换工具，计划优先兼容 Clash / Mihomo 生态。

An open-source tool for quickly switching proxy nodes, with initial support planned for the Clash / Mihomo ecosystem.

> **项目状态：立项筹备中。** 当前仓库提供项目定位、路线图和协作入口，尚无可运行程序或安装包。下文均为计划能力，不代表已经支持。

## 想解决的问题

切换常用节点不应该需要反复打开复杂控制面板、寻找策略组和确认当前选择。Node Switcher 希望让用户快速找到常用节点、完成切换，并明确知道操作是否成功。

## 产品目标

- **容易上手**：提供清晰的连接引导，尽量减少手动填写配置。
- **切换快捷**：集中展示策略组、当前节点和常用节点，减少操作步骤。
- **结果可信**：区分请求中、切换成功、连接失败和状态未知，避免显示虚假的成功状态。
- **面向更多用户**：以 Windows、macOS、Linux 为长期目标，实际支持范围以未来发布说明为准。
- **本地优先**：首版计划直接连接用户自己的本地代理控制接口，无需注册工具账号或上传配置。

## 首版计划

| 范围 | 计划 |
| --- | --- |
| 接入 | 连接已有 Clash / Mihomo 兼容控制接口，支持认证与连接诊断 |
| 查看 | 显示策略组、节点列表及当前选择 |
| 切换 | 切换可手动选择的策略组节点，并重新读取状态确认结果 |
| 常用 | 收藏节点，快速切换常用选择 |
| 配置 | 保存本机连接设置，提供清除凭据入口 |
| 分发 | 在确定首发平台及技术方案后提供安装和升级说明 |

首版聚焦管理已运行的代理客户端。节点售卖、订阅分发、代理内核运行管理和远程公网控制服务暂不纳入首版范围。

## 当前如何参与

1. 在 [Issues](https://github.com/foogooooooo/node-switcher/issues) 提交需求，说明操作系统、客户端和最常见的切换场景。
2. 阅读 [路线图](docs/ROADMAP.md)，参与首发平台、交互方式及兼容范围讨论。
3. 准备贡献代码前，先阅读 [贡献指南](CONTRIBUTING.md)。

目前尚未选择开发语言与 UI 框架，因此没有安装依赖或启动程序的步骤。选型完成后会补充可复现的独立开发环境和一键启动指令。

## 隐私与配置

请勿在 Issue、截图或 commit 中提交订阅地址、控制接口密钥、私人节点信息或完整客户端配置。讨论问题时请使用脱敏示例。

本项目不附带节点、订阅或第三方服务凭据，与 Clash / Mihomo 项目无隶属关系。
